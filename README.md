# pokedex-java

This project will allow users to search up Pokémon by either using Pokemon number or name. The program will return the Pokemon's name and general info (flavor text) along a picture and its top moves.

## Overview

The reason I wanted to make this project is because whenever I am playing a game of Pokemon, like FireRed or Emerald, I like for my Pokemon to have the best moves and it's always a pain to look it up every time. This will allow me to easily be able to look up pokemon and see its move list based off what game it is. 

## Features

- Return Pokemon with Sprite and Information
- (I want to it to return moves based on what game version it is set to)
